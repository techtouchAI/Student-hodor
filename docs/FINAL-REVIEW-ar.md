# المراجعة النهائية الشاملة — Student Hodor (حضور الطالب)

**التاريخ:** 2026-09-15 · **الإصدار:** 1.0.0+1 · **الفرع:** `arena/01a0a1b9-student-hodor`
**حالة بوابة الجودة:** `flutter analyze` صارم (صفر أخطاء/تحذيرات/ملاحظات) + كل الاختبارات خضراء + بناء APK موقّع بمفتاح إصدار مع تحقّق آلي من التوقيع — كلها تعمل في GitHub Actions عند كل دفعة.

---

## 1) ماذا بُني

تطبيق أندرويد **100% دون اتصال** لإدارة حضور الطلاب بالاعتماد على **بطاقات هوية مدرسية** تحمل باركود Code128 ورمز QR:

- مسح البطاقة بكاميرا الجهاز يسجّل الحضور فوراً (مع اهتزاز وتغذية راجعة صوتية/بصرية).
- من لم يُمسح حتى إقفال اليوم يُسجَّل **غائباً** تلقائياً — أو **بإجازة** إن كانت لديه إجازة تغطي اليوم.
- النتائج تُخزَّن لكل طالب عبر **السنة الدراسية كاملة**، وتُصدَّر إلى **Excel** و**PDF** بجداول ملوّنة يوم بيوم.

الصلاحيتان الوحيدتان في البيان: `CAMERA` و`VIBRATE`. **لا توجد صلاحية INTERNET إطلاقاً** — الأوفلاين ضمان تعاقدي مفروض في `AndroidManifest.xml`.

## 4) الاختبارات وبوابة الجودة

- **5 ملفات اختبار وحدة** تغطي النوى الحساسة: تشكيل عربي/ترتيب بصري، توليد وتحقق رمز البطاقة (checksum، تصادمات)، منطق أيام الدوام والعطل، **إقفال الجلسة** (بذرة كاملة: سنة/صف/3 طلاب/مسح/إجازة → تحقق من الغياب التلقائي واحترام الإجازة)، والتحويل الهجري (اتصال تسلسل الأيام ونطاقاته).
- **CI على كل دفعة:** pub get ← توليد كود drift ← `flutter analyze --fatal-warnings --fatal-infos` (صارم بالكامل: صفر ملاحظات) ← `flutter test` ← بناء universal + split-per-abi ← بصمات SHA256 ← **تحقّق آلي أن التوقيع بمفتاح الإصدار (CN=Student Hodor)** ← نشر Release ← تثبيت مفتاح التوقيع في المستودع (مرة واحدة).
- عند أي فشل: يلتزم CI سجلات التشخيص في `ci-diagnostics/` على الفرع نفسه (آلية العمل التي أدارت التصحيح عن بُعد دون بيئة بناء محلية).

## 6) حدود معروفة وقرارات تصميمية (بشفافية)

1. **الهجري جدوليّ (Kuwaiti):** قد يختلف ±يوم عن أم القرى — معتمد للعرض فقط وليس لأحكام شرعية.
2. **تشكيل العربية في PDF/Excel** يتم عبر المشكّل الداخلي `arabic_shaping.dart` (بدون harakat/تشكيل كامل) لأن مكتبات PDF في Dart لا تشكّل عربياً؛ بطاقات البادج تُصدَّر كصورة نقطية 300dpi فتظهر بخط Tajawal الكامل بلا أي قيد.
3. **مفتاح التوقيع في مستودع خاص** بكلمة مرور تطوير مثبتة — مقبول لسياق المدرسة؛ للتوزيع الأوسع يُنقل لاحقاً إلى GitHub Secrets.
4. **لا مزامنة سحابية** — بحكم المتطلب. الحماية: PIN محلي + نسخ احتياطي/دمج عبر SAF + نسخة إجبارية قبل أي تصفير.
5. الترميز داخل الباركود = المعرف المستقر + checksum فقط (قرار Appendix 2 المعلَن، لم يعترض عليه المستخدم) — التفاصيل مطبوعة على الوجه.
