# 🎓 حضور الطالب — Student Hodor

### نظام حضور الطلاب بالباركود و QR — أوفلاين بالكامل، من جهاز الأندرويد مباشرةً 📱

## 📖 نبذة عن التطبيق

**حضور الطالب** تطبيق أندرويد يعمل **دون اتصال نهائيًا** — لا خوادم، لا حسابات، لا صلاحيات إنترنت.
يصمم المعلم **بطاقات هوية مدرسية** لكل طالب تحمل اسمه وصورته ورمزَي `QR` و`Code128`، ثم يطبعها.
وفي الطابور الصباحي يكفيه **مسح البطاقة بكاميرا الجهاز** ليسجَّل الحضور فورًا مع اهتزاز وتغذية بصرية —
ومن لم يُمسَح حتى إقفال اليوم يُسجَّل **غائبًا** تلقائيًا، أو **بإجازة** إن كانت لديه إجازة تغطي اليوم.

كل البيانات تُخزَّن محليًا في قاعدة بيانات `SQLite`، وتُصدَّر النتائج إلى **جداول Excel ملوّنة**
و**تقارير PDF عربية** يومًا بيوم عبر السنة الدراسية كاملة.

## ✨ المميزات

| | الميزة | الوصف |
|---|---|---|
| 🪪 | **بطاقات طلابية قابلة للطباعة** | تصميم بطاقة لكل طالب تحمل اسمه وصورته وصفّه ورمزَي `QR` و`Code128` برمز تحقّق مضمّن |
| 📷 | **مسح فوري بالكاميرا** | قراءة البطاقات مباشرة عبر كاميرا الجهاز (محرك مسح مدمج يعمل أوفلاين) مع اهتزاز وتنبيه بصري |
| 🔒 | **إقفال اليوم الدراسي** | زر «بدء» و«إنهاء»: عند الإقفال يتحول كل من لم يُمسح إلى *غائب* تلقائيًا — بلا ادخال يدوي |
| ⏱️ | **وقت التأخير الفعلي** | كل تسجيل «متأخر» يُثبَّت معه وقت الوصول الحقيقي (ساعة ودقيقة) ويُعرض في كل شاشة فيها فقرة التأخير |
| 📅 | **تقويم أيام الدوام** | تحديد أيام الدوام الأسبوعية وعطلة نهاية الأسبوع وجدول العطل الرسمية القابل للتعديل |
| 🏖️ | **إجازات الطلاب** | تسجيل الإجازات ومزامنتها تلقائيًا مع سجل الحضور (غياب ⇄ إجازة) |
| 📊 | **تقارير يومية وشهرية** | كشف حضور لكل صف ولكل طالب عبر السنة، مع **جداول ملوّنة** حسب الحالة |
| 🔔 | **تنبيه حد الفصل** | زر تنبيه أعلى التطبيق (بجانب اسمه) بشارة عدد غير المقروء؛ لحظة بلوغ أي طالب الحد الثاني (حد الفصل) يُنشأ تنبيه **داخل التطبيق** وإشعار **منبثق من نظام أندرويد** بقناة مخصصة — والضغط على أيٍّ منهما يفتح ملف الطالب |
| 📤 | **تصدير Excel و PDF** | ملفات عربية كاملة (بما فيها التشكيل العربي) جاهزة للمشاركة والطباعة |
| 📕 | **تصدير الغيابات فقط** | قسم مستقل في **إكسل و PDF** يعرض غيابات كل طالب وحدها — بالتاريخ واليوم وطريقة التسجيل |
| 🏫 | **سنوات دراسية وصفوف** | إدارة السنوات والصفوف والشعب والطلاب مع الترحيل والترقية، وحذف أي سنة بنطاقها مع نسخة احتياطية إجبارية |
| 🗓️ | **التاريخ الهجري** | عرض مقابل هجري في كامل الواجهة |
| 🔐 | **قفل التطبيق** | حماية التطبيق برمز `PIN` |
| 💾 | **نسخ احتياطي واستعادة** | تصدير كامل لقاعدة البيانات والإعدادات في ملف واحد واستعادته على أي جهاز — وقبل أي حذف تُحفظ نسخة إجبارية في مجلد التنزيلات «نسخة احتياطية للغيابات» باسم يميزها بالسبب والتاريخ والوقت |
| 🔤 | **خط أميري** | واجهة عربية أصيلة بخط `Amiri` المضمّن |

## 🛡️ الخصوصية والأذونات

> التطبيق **لا يطلب صلاحية الإنترنت إطلاقًا** — الأوفلاين ضمان مفروض في `AndroidManifest.xml` نفسه.

| الصلاحية | السبب |
|---|---|
| 📷 `CAMERA` | مسح بطاقات الطلاب فقط |
| 📳 `VIBRATE` | تغذية راجعة عند نجاح القراءة |
| 🔔 `POST_NOTIFICATIONS` (أندرويد 13+) | إشعار نظام منبثق عند بلوغ الطالب حد الفصل — تُطلب بموافقة المستخدم، وقابلة للإيقاف من الإعدادات |

لا إعلانات، لا تتبّع، لا خوادم خارجية — بيانات الطلاب لا تغادر الجهاز إلا بنسخة احتياطية يُنشئها المستخدم بنفسه.

> 🔏 صلاحيات الشبكة التي تضيفها مكتبة ML Kit إلى البيان المدمج (`INTERNET` و
> `ACCESS_NETWORK_STATE`) **مُزالة صراحةً** في `AndroidManifest.xml`، حفاظاً على
> هذا العقد. وسياسة مفتاح التوقيع (سبب «التحديث لا يُثبَّت») موثّقة في
> [RELEASE-SIGNING-ar.md](docs/RELEASE-SIGNING-ar.md).

## 🏗️ التقنيات المستخدمة

| المجال | التقنية |
|---|---|
| 🖥️ الإطار | **Flutter** (Dart ≥ 3.5) — واجهة عربية كاملة `RTL` |
| 🧠 الحالة والتنقل | **Riverpod** + **go_router** |
| 🗄️ قاعدة البيانات | **Drift** فوق **SQLite** محلية مع فهارس وترحيل مخطط |
| 📷 المسح | **mobile_scanner** (MLKit مدمج، يعمل أوفلاين) |
| 🔳 توليد الرموز | **qr** و **barcode** (رمز `SH-{مدرسة}-{تسلسل}-{سنة}-{تحقق}`) |
| 📤 التصدير | **excel** + **pdf** + **printing** مع تشكيل عربي مخصص |
| 🔔 الإشعارات | **flutter_local_notifications** — إشعارات نظام محلية (قناة مخصصة + صلاحية أندرويد 13+) بلا أي اتصال |
| 🗓️ الهجري | تحويل هجري جدولي (خوارزمية كويتية) للعرض |
| 🔊 تجربة المسح | **wakelock_plus** + **vibration** |

## 🚀 التشغيل من المصدر

**المتطلبات:** حزمة [Flutter](https://docs.flutter.dev/get-started/install) المستقرة (`≥ 3.5`) مع أدوات أندرويد.

**متطلب الجهاز المشغّل:** أندرويد **7.0 (API 24)** فأحدث — رُفع الحد الأدنى من
5.0 في الإصدار 1.3.0 لأن وسائط الإشعارات الحديثة تتطلبه.

**تثبيت حزمة APK جاهزة:** حمّل الملف المناسب من وسم `latest-apk` في
[صفحة الإصدارات](../../releases/latest)، واتبع
[دليل التثبيت وتشخيص أعطال التثبيت](docs/INSTALL-ar.md).

<div dir="ltr">

```bash
# 1) استنساخ المستودع
git clone https://github.com/techtouchAI/Student-hodor.git
cd Student-hodor

# 2) جلب الاعتماديات وتوليد أكواد Drift
flutter pub get
dart run build_runner build --delete-conflicting-outputs

# 3) التشغيل على جهاز أندرويد متصل
flutter run
```

</div>

**بناء ملف APK موقّع:**

<div dir="ltr">

```bash
flutter build apk --release
```

</div>

> 💡 الإصدارات تُبنى وتُوقَّع آليًا عبر **GitHub Actions** عند كل دفعة إلى `main`.

## 🧪 الاختبارات وضمان الجودة

بوابة الجودة تعمل في كل بناء على `GitHub Actions`:

- ✅ `flutter analyze --fatal-infos` — صفر أخطاء وتحذيرات وملاحظات
- ✅ اختبارات وحدة تغطي: رموز البطاقات، التشكيل العربي، التقويم الهجري،
  مفاتيح الأشهر، مزامنة الإجازات، إقفال الجلسات، النسخ الاحتياطي، وتصدير Excel
- ✅ بناء `APK` موقّع مع تحقق آلي من صحة التوقيع
- ✅ **بوابة نشر** (`tools/verify_apk.py`): تمنع نشر حزمة لا تُثبَّت — سلامة
  الأرشيف، التحقق من التوقيع بكل المخططات، محاذاة 16KB للمكتبات الأصلية،
  و**مقارنة الحزمة الجديدة بالمنشورة فعلاً** (استمرار مفتاح التوقيع، تزايد
  `versionCode`، عدم ارتفاع `minSdk`)
