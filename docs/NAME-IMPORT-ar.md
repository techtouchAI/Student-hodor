# استيراد أسماء الطلاب من ملف (الملحق أ)

> الملف الوظيفي: `lib/core/name_import.dart` (قراءة/تنظيف/معاينة — بلا قاعدة
> بيانات وبلا واجهة)، و`AppDb.importStudentNames` (كتابة واحدة)، وشاشة
> `lib/features/students/import_names_screen.dart` (معاينة ثم تأكيد).

## 1. الوسائط

| الوسيط | الحالة |
|---|---|
| `.txt` UTF‑8 (بعلامة ترتيب أو بلا) | ✅ |
| `.txt` UTF‑16LE/BE بعلامة ترتيب | ✅ (ملفات Notepad «Unicode») |
| `.txt` Windows‑1256 | ✅ ارتداد تلقائي حين يفشل UTF‑8 (جدول مايكروسوفت الرسمي) |
| `.docx` فقرات | ✅ |
| `.docx` جدول | ✅ مع استدلال عمود الاسم |
| `.doc` الثنائي | ❌ يُرفض: «احفظه من Word بصيغة .docx أو .txt» |

## 2. قواعد القراءة

1. **اسم في كل سطر**، أو جدول بأعمدة.
2. نزع الترقيم البادئ: `1.`، `1-`، `١.`، `(3)`، `#7`، `-`، `•` (مرتان كحدّ أقصى).
3. تخطّي **الترويسة**: «الاسم»، «اسم الطالب»، «الأسماء»، «ت»، «م»، «الرقم»،
   «الشعبة»، «الصف»، «ملاحظات»… (المقارنة بعد التطبيع).
4. تخطّي **عنوان المستند**: «قائمة الطلاب»، «كشف…»، «مدرسة…»، «الصف السادس…»؛
   ولا يُخطئ في اسم مثل «أسماء محمد» لأن العبارة الكاملة هي المطابقة.
5. تخطّي الأسطر الفارغة والرقمية الصرفة وعلامات الصفحات.
6. **عمود الاسم** في الجداول: تُحسب لكل عمود نسبة الخلايا التي تُشبه اسماً
   (حروف ≥ 2، بلا أرقام)؛ يُختار الأعلى (≥ 50٪)، ويُذكر رقمه في المعاينة.
   الجدول الذي لا عمود اسمي فيه يُسجَّل «جدول بلا عمود اسمي» ولا يُنتج أسماء.

## 3. التطبيع

* قصّ الفراغات وتوحيد المسافات، وحذف التشكيل والتطويل والمحارف الصفرية.
* حد أقصى 120 محرفاً (حد المخطط)؛ الأطول يُتخطّى بسبب صريح.
* الهمزات والتاء المربوطة **تبقى كما هي** في الاسم المحفوظ (نص يُطبع)؛
  توحيدها يقع في مفتاح التشابه فقط (`studentNameKey` عبر `normalizeName`).

## 4. منع التكرار

* مكرر داخل الملف (بمفتاح التشابه) ⇒ يُسقَط ويُعدّ، ويُعرض سببه.
* مطابق لاسم موجود في **الصف نفسه** ⇒ يُعرض في المعاينة ويُتخطّى افتراضياً
  (مفتاح «تجاهل الأسماء الموجودة» مفعّل). لا يُحذف ولا يُعدَّل أي طالب قائم.
* صف آخر بالاسم نفسه لا يمنع الاستيراد: السياق صف + شعبة.

## 5. الوعد الذرّي

`importStudentNames` يعمل داخل `transaction` واحدة: التسلسل يبدأ بعد آخر
تسلسل في السنة (الترتيب محفوظ)، ولكل طالب باجه الأول كما في `addStudent`،
وأي فشل في المنتصف يُرتدّ كاملاً — لا استيراد نصفي.

## 6. الاختبارات

`test/name_import_test.dart`:

| الاختبار | يثبت |
|---|---|
| نص UTF‑8 بعلامة ترتيب | نزع الترقيم، تخطّي الترويسة والعنوان والفارغ، الترتيب |
| Windows‑1256 | فكّ صحيح لملف Notepad قديم |
| UTF‑16LE | فكّ صحيح للنص «Unicode» |
| `.doc` | رفض برسالة صريحة |
| Word فقرات + جدول | استدلال عمود الاسم، تخطّي الترويسة والعمود الرقمي |
| جدول بلا عمود اسمي | لا أسماء وهمية + سبب مسجَّل |
| التطبيع | تشكيل/تطويل/مسافات/الحد الأقصى/نزع الترقيم |
| المكرر | إسقاط المتشابه داخل الملف مع السبب |
| الاستيراد | ترتيب `seq`، باجات، عدّ غير الصالح، إعادة الاستيراد بلا تكرار |
| صف آخر | الاستيراد مقيّد بالصف والشعبة |
